# 3D-pet Wiki

> A desktop AI engineering team living on macOS.  
> 住在 macOS 桌面上的 AI 工程團隊。  
> macOS デスクトップで暮らす AI エンジニアリングチーム。

3D-pet combines an Electron transparent overlay, VRM characters, and local coding-agent subscriptions. Each pet can be assigned its own project, model, personality, permissions, and conversation session.

## Core capabilities

- Multiple independent VRM pets on one desktop.
- Codex or Claude Code bound to each pet through local CLI subscriptions.
- Project-aware conversations, queued tasks, approval feedback, and a shared control center.
- Pixel-level click-through, animations, lighting, physics tuning, and power-aware rendering.
- Traditional Chinese, English, Japanese, and Korean application UI.

Project source and issue tracking live in the main GitHub repository. This Wiki is maintained as a separate Git repository, following GitHub's wiki model.

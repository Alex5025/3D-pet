# 使用手冊

## 管理多隻寵物

從 Tray 或角色右鍵選單新增、切換、休息或喚醒寵物。相同工作目錄的寵物會歸在同一專案群組；泡泡會顯示專案根目錄最後一層名稱。

「休息」會釋放 WebGL、快取與 agent session runtime；下次喚醒時仍保留持久化設定。也可只重啟目前角色，或用地端 PID 腳本重啟整個寵物系統。

## 與 AI 對話

- 執行中仍能繼續輸入，訊息會排入佇列並自動接續。
- 可貼上 PNG、JPEG 或 WebP；最多 4 張、單張 8 MiB。
- 回覆支援 GitHub Flavored Markdown 類型的常用 Markdown 顯示。
- 「＋ 新對話」會清除目前 session，下一句從新上下文開始。
- 可隨時按「停止」中斷工作。

## 權限與審批

| 權限 | 適用情境 |
|---|---|
| 唯讀 | 問答、分析與檢查，不修改檔案 |
| 可寫且詢問 | 日常開發；高風險操作先顯示核准框 |
| 全自動 | 可信工作區中的自動化工作，請謹慎使用 |

拒絕操作時可填寫希望如何調整。Claude 會收到拒絕訊息；Codex 會把調整方向送入同一輪對話。沙盒設定由 Electron main 直接修改工作目錄的 `.codex/config.toml`，不交由 AI 執行。

## 拖放參考資料

將檔案或資料夾拖向寵物。macOS 的特殊透明疊層無法直接接收 OS 拖放，因此系統會在角色位置顯示一般屬性的半透明接收窗。

- 一般檔案／資料夾：路徑加入對話參考清單。
- `.vrm`：替換角色模型。
- `.vrma`：播放動作。

## 中控面板

中控面板提供：

- 所有寵物的休息、閒置、工作中與等待審批狀態。
- 對指定寵物指派任務。
- 把任務放入公用任務池，讓空閒寵物認領。
- 集中處理審批。
- 管理逐寵 Codex 沙盒設定與介面語言。

## 外觀與效能

- 可調平行光／點光源、陰影、髮絲、衣服、胸部與尾巴晃動。
- 支援預設姿勢與 20–60 秒隨機待機動作。
- 閒置時降低更新頻率；電池、過熱、鎖屏或睡眠時會進一步節流或暫停。

## 常見問題

### 泡泡不會消失

確認圖釘是否啟用。未釘選的泡泡即使 agent 正在執行，也會在游標移開後收起。

### 審批後畫面像卡住

目前版本會在送出選擇前釋放輸入焦點。若仍發生，先重啟目前角色，並查看 terminal 的 agent log。

### 系統重啟失敗

查看 `runtime-data/pet-system-restart.log`。地端腳本會讀取 `runtime-data/pet-system.pid`，終止舊 PID 後重新執行 `npm run dev`。

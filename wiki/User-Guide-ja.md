# ユーザーガイド

## 複数ペットの管理

Tray またはペットのコンテキストメニューから、追加、切替、休憩、復帰、再起動を行えます。同じ作業ディレクトリのペットは同じプロジェクトグループにまとめられ、会話バブルにはプロジェクトルート末尾のフォルダー名が表示されます。

休憩すると WebGL、キャッシュ、ライブ agent runtime を解放しますが、永続設定は残ります。現在のペットだけを再起動することも、ローカル PID スクリプトでシステム全体を再起動することもできます。

## AI アシスタントとの会話

- タスク実行中に入力したメッセージは自動的にキューへ入ります。
- PNG、JPEG、WebP を最大 4 枚、1 枚 8 MiB まで貼り付けられます。
- 応答はサニタイズ済み Markdown として表示されます。
- **新しい会話**で session context をリセットできます。
- **停止**で現在のタスクを中断できます。

## 権限と承認

| レベル | 用途 |
|---|---|
| 読み取り専用 | 質問、分析、調査 |
| 書き込み＋承認 | 通常開発。危険な操作は事前確認 |
| 自動 | 信頼済み workspace の自動化。慎重に使用 |

操作を拒否するときは、希望する修正方針も入力できます。Claude には拒否メッセージとして、Codex には同じ turn への steer として送られます。Sandbox 設定は AI を経由せず Electron main が `.codex/config.toml` に直接書き込みます。

## 参照ファイルのドロップ

ファイルまたはフォルダーをペットへドラッグします。macOS の特殊な透明オーバーレイは OS のドロップイベントを受け取れないため、キャラクター位置に通常属性の半透明受信ウィンドウが表示されます。

- 通常ファイル／フォルダー：会話の参照情報になります。
- `.vrm`：キャラクターモデルを交換します。
- `.vrma`：モーションを再生します。

## コントロールセンター

- 全ペットの休憩、待機、作業中、承認待ち状態を一覧表示。
- 特定のペットへ直接タスクを割り当て。
- 空いているペットが取得できる共有タスクプール。
- 承認を一か所で処理。
- ペットごとの Codex sandbox と UI 言語を設定。

## 表示と省電力

平行光／点光源、影、髪、服、胸、しっぽの揺れを調整できます。起動ポーズとランダムな待機モーションにも対応しています。待機中は描画頻度を下げ、バッテリー駆動、熱負荷、画面ロック、スリープに応じてさらに制限または停止します。

## トラブルシューティング

### バブルが閉じない

ピンが有効になっていないか確認してください。ピン留めされていないバブルは agent 実行中でもポインターを離すと閉じます。

### 承認後に画面が固まったように見える

現在の版では選択 UI を閉じる前に入力フォーカスを解放します。再発する場合は現在のペットを再起動し、terminal の agent log を確認してください。

### システム再起動に失敗する

`runtime-data/pet-system-restart.log` を確認してください。ローカルスクリプトは `runtime-data/pet-system.pid` を読み、旧プロセスを終了して `npm run dev` を再実行します。

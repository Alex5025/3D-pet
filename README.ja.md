# 3D-pet — デスクトップに住む AI エンジニアリングチーム

[繁體中文](README.md) | [English](README.en.md) | **日本語**

macOS の透明オーバーレイ上で動く VRM 3D デスクトップペット(Electron + three.js + [@pixiv/three-vrm](https://github.com/pixiv/three-vrm))——ただの飾りではありません。**それぞれのペットに本物のコーディングエージェント**(OpenAI Codex または Claude Code)と作業ディレクトリが紐づいています。吹き出しにひとこと頼めば、ペットがコードを修正し、テストを走らせ、ドキュメントを書き、危険な操作の前にはあなたの承認を求め、終わったら表情とモーションつきで報告してくれます。

一匹ならデスクトップペット、数匹揃えばエンジニアリングチーム。

## ここがすごい

- **本当に仕事をするペット**——チャットのおもちゃではありません。ペットごとに独立したエージェント・モデル・推論強度・ペルソナ・作業ディレクトリ。ファイルをドラッグして参考資料に、スクリーンショットを貼って読ませて、あなたのリポジトリで実際に手を動かします。
- **API 課金なし**——ローカル CLI のサブスクリプションログイン(Codex CLI / Claude Code)のみを使用。API キー不要、請求書の心配もなし。
- **マルチペット協働**——チャットにはキューがあり(入力欄は一切ロックされず、メッセージは順番に実行)、タスクは特定のペットへ割り当てるか、**共有タスクプール**に投げて手すきのペットに拾わせることも。**コントロールパネル**で全ペットの状態を一覧し、承認の代理応答や一括指示ができます。
- **効く権限管理**——3 段階の権限(読み取り専用/作業ディレクトリ書き込み+承認/全自動)。承認を却下するときフィードバックを添えれば、AI は同じターン内で方針を修正。Codex のサンドボックスポリシーはメインプロセスが直接管理——AI には触らせず、任意スクリプトも実行しません。
- **デスクトップペットとしての完成度**——ピクセル単位のクリック透過(透明部分はマウスが素通り)、視線追従、ドラッグ移動/回転/ズーム、待機モーションのランダム再生。**部位ごとの物理調整**:髪・服・しっぽの揺れをそれぞれ別々にチューニングできます——キツネのしっぽのふわふわな揺れは、自分で作り込めるんです。アイドル時の自動スロットリング、バッテリー/発熱時のダウンシフト、画面ロックで完全停止——常駐させても軽いまま。
- **4 言語 UI**——繁体字中国語/英語/日本語/韓国語。デフォルトはシステム追従で、AI の返答言語も切り替わります。

## 機能一覧

**ペット本体**
- 任意の VRM モデルに交換可能(トレイメニュー/受け取りウィンドウへのドラッグ&ドロップ)。複数ペットの同時起動、それぞれ独立した設定
- 視線がカーソルを追従。ドラッグで移動、右ドラッグで回転、スクロールでズーム。透明部分はピクセル単位でクリック透過
- ライティング(平行光源/点光源/影)、**部位ごとの物理揺れ**(髪/服/胸/しっぽ——スプリングボーンを個別調整)、衣装の表示切り替え
- VRMA モーション再生、起動時ポーズ、待機モーション(セットを選ぶと 20〜60 秒間隔でランダム再生)
- 電力ティア:アイドルスロットリング + `powerMonitor` 連動(バッテリー/発熱でダウンシフト、ロック/スリープで完全停止、ProMotion ディスプレイは設計値の 60Hz にクランプ)
- ペットは「休憩」でリソース解放(WebGL コンテキスト/キャッシュ/エージェントセッション)、必要なときに起こせます

**AI アシスタント(吹き出し)**
- ペットごとに **Codex**(`codex app-server`、JSON-RPC 常駐)または **Claude Code**(CLI spawn)をバインド。モデルは動的リスト、推論強度 low〜ultra、ペルソナは system prompt に注入
- **チャットキュー**:実行中も入力欄はロックされず、メッセージは自動で順次実行。各メッセージは取り消し可能
- 返答は Markdown レンダリング(GFM、DOMPurify サニタイズ)、モデル/強度バッジ、外側のステータスカプセル(実行中/承認待ち/完了——既読になるまで消えません)
- **画像メッセージ**:PNG/JPEG/WebP を入力欄に直接ペースト(最大 4 枚、各 8 MiB)、AI が読めます
- **参考ファイルのドラッグ&ドロップ**:ファイル/フォルダをペットに向かってドラッグし、光った受け取りウィンドウにドロップ——絶対パスが吹き出しに並び、会話に注入されます
- **吹き出しの気配り**:ピン留めで常時展開、左右の端をドラッグして幅を手動調整(ダブルクリックで自動に戻る)、幅は内容に応じて伸縮、起きているペットが多いときは上限を自動で狭めます
- セッション永続化(アプリ再起動後も会話を継続)、ターン中断可、クラッシュ時自動再接続、「+ 新しい会話」でコンテキストをクリア
- **ペットツール(MCP)**:エージェントが `pet_play_motion` / `pet_show_expression` / `pet_speak` を自発的に呼び出し、働きながら演技します

**マルチペット協働(コントロールパネル)**
- ペットごとの状態リスト(休憩/待機/作業中/承認待ち)、最終アクティビティ順にソート
- 一括指示:特定のペットに割り当て、または**共有タスクプール**へ発行(ワークスペース限定も可)して手すきのペットに拾わせる。タスク台帳が queued→running→done の全ライフサイクルを追跡
- 承認の代理応答:パネルから承認でき、吹き出しとパネルは同期して閉じます
- サンドボックスタブ:ペットごとに Codex の承認ポリシー/サンドボックスモード/ネットワークアクセスを調整——Electron メインプロセスがワークスペースの `.codex/config.toml` を直接書き換え、AI は経由しません
- UI 言語セレクタ(繁体字中国語/英語/日本語/韓国語)

**設計段階からの安全性**
- 3 段階の権限:読み取り専用/作業ディレクトリ書き込み(吹き出しに承認が出る)/全自動。却下時のフィードバックで同ターン内の軌道修正が可能
- `workspace-write` でも多くの場合 `.git` は保護されます。commit/push には明示的な同意、または信頼できるプロジェクトでの一時的なフルアクセス(二重確認あり)が必要
- 新しいペットには専用の作業ディレクトリを自動作成(`~/Documents/PetWorkspaces/<ペット名>_<タイムスタンプ>/`)——他のプロジェクトを汚しません

## 動作環境

- macOS(Apple Silicon で実測)
- Node.js 22+
- AI 機能を使う場合:[Codex CLI](https://github.com/openai/codex) と/または [Claude Code](https://claude.com/claude-code) がインストール・ログイン済み(サブスクリプションアカウント)

## クイックスタート

```bash
npm install
npm run dev
```

- キャラクターがデスクトップに現れます。マウスがペットに重なると操作可能に、離れると自動でクリック透過に戻ります。
- **会話**:ペットにカーソルを乗せる → 吹き出しに入力 → Enter で送信(Shift+Enter で改行)。実行中に入力を続けると自動でキューに並びます。
- **ペットを右クリック(またはトレイアイコン)**:ペットの切り替え/追加、VRM ファイル選択、モーション、設定、**コントロールパネル**、サンドボックス設定、位置リセット、休憩/起こす、ペット単体またはシステム全体の再起動。
- **設定パネル**のタブ:ライティング/キャラクター(名前・ペルソナ・揺れ・衣装)/モーション(既定ポーズ・待機モーション)/ワーク(エージェント・モデル・強度・権限・作業ディレクトリ)。

モデルは `models/`、モーション(.vrma)は `motions/` へ。実行時データは `runtime-data/`(いずれも git 管理外)。

> `.codex/config.toml` にはプロジェクトのサンドボックスポリシーやローカルパスが含まれることがあります。コミット前に内容を確認してください。認証情報・トークン・API キーは決してリポジトリに入れないこと。

## 開発と検証

```bash
npm run typecheck && npm run build

VRM_PET_DATA_DIR=$(mktemp -d) VRM_PET_AGENT_SELFTEST=1 npm run dev       # MockProvider による全チェーン自己テスト
VRM_PET_DATA_DIR=$(mktemp -d) VRM_PET_AGENT_SELFTEST=claude npm run dev  # 実 claude e2e(サブスク枠を消費)
VRM_PET_DATA_DIR=$(mktemp -d) VRM_PET_AGENT_SELFTEST=codex npm run dev   # 実 codex e2e(サブスク枠を消費)
VRM_PET_AGENT_MOCK=1 npm run dev                                          # フェイクエージェントで UI 確認、枠消費なし
VRM_PET_AGENT_DEBUG=1 npm run dev                                         # エージェントの argv/payload をダンプ
VRM_PET_PERF_LOG=1 npm run dev                                            # パフォーマンス計測(オーバーレイに DevTools がないための唯一の窓口)
```

ブラウザ検証ページ(dev server 起動後):レンダリングは `/vrmtest.html`(`window.__viewer`)、吹き出しは `/bubbletest.html`(`window.__bubble`)。

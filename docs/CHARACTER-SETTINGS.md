# 角色設定參數說明

以下以 `characters.yaml` 的結構逐項解釋參數。數值僅為示例；ID、模型指紋及路徑是佔位文字，請勿直接覆蓋實際設定。

```yaml
schemaVersion: 3 # 整份設定檔的格式版本，由程式管理。

characters: # 角色清單；每個「-」代表一個獨立角色。
  - schemaVersion: 1 # 單一角色的格式版本，由程式管理。
    id: "角色唯一識別碼" # 區分角色的固定 ID；改用不同 AI 模型不會改變角色身分，請勿手動修改。
    modelHash: "VRM 檔案的 SHA-256 指紋" # 由程式計算，辨識 VRM 內容；不是角色 ID，也不是 AI 模型名稱。
    vrmPath: "/完整路徑/角色.vrm" # 此角色使用的 VRM 外觀檔案；建議透過介面選擇模型。

    parameters: # 此角色獨立的參數；同一角色在不同工作樹共用。
      name: "角色名稱" # 顯示名稱，必填且不可只有空白，最多 200 字。
      persona: |- # 個性、語氣與處事方式，提供給 AI 作為對話提示，最多 4000 字。
        個性活潑親切，重視承諾。
        使用繁體中文，回覆簡潔，主動說明進度與障礙。

      lighting: # 光影設定；省略整組時使用程式預設值。
        type: directional # directional＝平行光，類似陽光；point＝點光源，類似燈泡。
        ambient: 1.8 # 環境光亮度，0～7；越高，角色整體越亮。
        directional: 1.05 # 主光亮度，0～500；平行光與點光源都使用此值。
        x: 0 # 光源左右位置，-1000～1000，單位公尺，原點為角色腳邊。
        y: 1 # 光源上下位置，-1000～1000；正值在角色腳邊上方。
        z: 2 # 光源前後位置，-1000～1000；正值朝螢幕觀看者。
        # 平行光使用上述位置決定照射方向；點光源的位置與距離都影響照明。
        shade: 0.25 # MToon 陰影加深比例，0～1；0 保留模型原色，越大陰影越深，不是地面投影開關。
        temperature: 6500 # 色溫，1800～12000 K；低值暖橘、高值冷藍，6500 約中性白。
        # temperature 同時影響環境光與主光；省略時為 6500。
        # 若提供 lighting 區塊，除 temperature 外的欄位都必須填寫。

      sway: # 物理晃動強度，各項 0～2；1＝模型原設定，接近 0 抑制晃動，越大越柔軟。
        hair: 1.44 # 頭髮晃動。
        cloth: 1.58 # 衣服晃動，例如裙襬、袖子與緞帶。
        chest: 2 # 胸部晃動。
        tail: 1.54 # 尾巴晃動。
        # 依模型骨骼名稱分類；模型沒有對應物理骨骼時，該項不生效。
        # 可以省略整組；若提供 sway 區塊，四個欄位都必須填寫。

      wardrobe: # 模型部件／材質的顯示開關；true＝顯示，false＝隱藏。
        Hair: true # 顯示名為 Hair 的部件；不影響頭髮晃動強度。
        Cloth_Pants: false # 隱藏名為 Cloth_Pants 的部件。
        "0": true # 數字也是模型提供的識別名稱，無法單靠數字判斷部位。
        # 上述鍵名僅為示例，必須對應目前 VRM 內的名稱，大小寫也必須一致。
        # 模糊名稱或雜湊名稱請透過介面確認部位，不要自行改名或猜測。
        # 每個值必須是布林值 true／false，不能加引號變成字串。
        # 最多 10000 項，每個鍵名最多 1000 字。

      defaultPose: "01-全身展示.vrma" # 預設姿勢的動作檔名，只填檔名，不含目錄。
      idleMotions: # 待機時可隨機播放的動作清單，最多 50 項；填 [] 表示不選用隨機待機動作。
        - "01-全身展示.vrma" # 每一項都是 motions 資料夾內的 .vrma 檔名。
        - "02-打招呼.vrma"
        # 動作檔名最多 255 字，必須以 .vrma 結尾，且不可包含目錄分隔符號。
        # 檔案必須實際存在；填入名稱不會自動下載或建立動作檔。
```

未出現的選填參數表示未明確設定，不必為了補齊欄位而新增數值。`wardrobe.Hair` 控制顯示，`sway.hair` 控制晃動，兩者用途不同。

共用設定預設位置：macOS 為 `~/Library/Application Support/VRM Pet/runtime-data/characters.yaml`；Windows 為 `%APPDATA%\VRM Pet\runtime-data\characters.yaml`。動作檔放在同一產品資料目錄的 `motions/`。

介面異動送達主程序後立即儲存；光影、晃動及位置的高頻操作保留約 50ms 傳送節流。儲存時合併不同欄位的外部修改，同一欄位有不同修改則提示衝突並保留磁碟內容；手動修改檔案後，角色需休息再喚醒才載入。port、工作目錄、AI 模型與 Agent 綁定屬於各工作樹本地設定，不放在此檔案。YAML 內註解可能在程式儲存時被移除，本說明文件會保留。

參數定義依據：[欄位驗證](../src/shared/character.ts)、[渲染參數](../src/renderer/viewer.ts)。
